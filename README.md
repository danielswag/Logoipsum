# Logoipsum
Modern SaaS landing page for a subscription-based business, featuring a hero section, feature blocks, metrics, benefits, and pricing plans. Built with HTML, CSS with a focus on clean layout, typography, responsive design, and reusable frontend components.

#Features

Modern SaaS-style landing page

Hero section with call-to-action buttons

Feature and metrics sections

Pricing plans

Responsive layout

Clean and structured UI

#Technologies

HTML5

CSS3

Purpose

This project was created as a frontend practice project to improve skills in building landing pages, working with layouts, typography, spacing, reusable styles, and responsive design.
